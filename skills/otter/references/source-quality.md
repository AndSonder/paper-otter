# 来源与学习价值门槛

这个门槛在个性化排序之前执行。它回答的不是“论文有名吗”，而是“它是否值得读者拿出一次完整阅读时间”。

## 1. 先核验来源

优先从会议论文集、期刊页面、arXiv 原文、作者项目页、研究机构或公司的官方技术报告获取材料。记录：

- `kind`：`conference`、`journal`、`official-report`、`preprint` 或 `other`；
- `venue`、年份和是否经过同行评审；
- 发布组织与原始链接；
- 版本状态，例如正式论文、预印本、更新中的技术报告。

主读优先考虑本领域公认的高质量会议或期刊论文，以及有完整方法、实验与局限讨论的机构官方报告。顶会或大厂只提高来源可信度的先验，不能替代内容判断。普通预印本可以入选，但必须有明显的新机制、充分证据或对当前问题不可替代的价值，并清楚标注其发表状态。

## 2. 再判断是否撑得起一次精读

逐项写一句证据，不使用“很有启发”“值得一读”这类空话：

- **问题分量**：解决的是反复出现的关键瓶颈，还是只覆盖很窄的特殊情形？
- **机制深度**：读者能否追踪设计约束、关键操作和代价，而不只是记住一个技巧？
- **证据深度**：有没有足够的推导、对照、消融、规模实验或生产数据支持核心结论？
- **迁移价值**：读完后形成的判断，能否用于其他模型、系统或工作负载？
- **读者新信息**：相对读者已经掌握的内容，它是否提供非显然的新认识？

至少前三项必须有实质内容。只有“一个直觉、一个小改动、少量窄实验”的工作，即使主题匹配，也不能作为主读。综述、经验研究和复现工作不要求新架构，但必须提供可靠的分类、测量或反常识结论。

## 3. 分配候选身份

- `main-eligible`：来源已核验，且足以支撑当天的完整阅读目标。
- `alternative`：质量合格，但和当前目标、难度或时间预算的匹配度较低。
- `exploration`：方向值得观察，但证据、成熟度或相关性仍不够；只能作为明确标注的探索项。
- `reject`：来源不可核验、核心贡献过薄、证据不足、与近期内容高度重复，或无法回答当前问题。

候选身份不是永久评级。新版本、正式发表或读者目标改变后可以重审。

## 4. 留下可审计记录

每个候选在当天审计文件中至少保存：

```json
{
  "publication": {
    "kind": "official-report",
    "venue": null,
    "peerReviewed": false,
    "organization": "Example Lab",
    "primaryUrl": "https://example.org/report.pdf",
    "status": "technical-report"
  },
  "admission": {
    "role": "main-eligible",
    "problemWeight": "...",
    "mechanismDepth": "...",
    "evidenceDepth": "...",
    "transferValue": "...",
    "readerNovelty": "...",
    "uncertainties": []
  }
}
```

先保存这些判断，再做个人排序。总分只能是排序辅助，不能覆盖准入结果。
