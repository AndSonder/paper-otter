# 来源与图文

提取论文证据或规划配图时读取。

有论文链接就读相关原文，不按标题或摘要补实验和推导。证据笔记记录主张、条件、原文定位、必要计算和未核实处。“当前资料没写”不等于“研究没做”；“只、没有、首次”等判断要有来源。数值比较核对两端方案、单位、基线和配置，不把理论成本当实测加速。

图要替读者完成一次观察。关系、状态变化和并行时序适合图；一个短式就能说明的事情不用强配。先检查论文原图能否回答当前问题。遇到 arXiv，按 [references/arxiv-source-figures.md](arxiv-source-figures.md) 固定版本、检查源码、核对 caption 和正文引用，再使用原图。不能仅凭文件名猜图号。

图前告诉读者看哪里，图后解释观察怎样推进结论。保留关键坐标、图例、条件、图号与来源；裁切或重绘标明改动。自己画的机制图标为示意，不能伪装成实验结果。图中统计范围与正文一致，单设备、整机或单计算单元不能混用。公式和精确结构用 SVG、Mermaid 或绘图程序，统计图用标准绘图库。

交付前按正文要求的读图动作，在阅读栏宽度下实际辨认相关文字、连线与数值，提供简短替代文字。若核心推理必须追踪的细节太小，就选取清晰局部或另画简图，并保留全图参照；高清入口供进一步查看，不能代替正文所需的观察。无法看到图就记录未检。图片存在和路径有效不等于图文解释完成。

具体实验数字需要最终读者可追溯的出处。输入中的未核实记录留在证据笔记；除非用户任务就是分析这份记录，否则不将无名记录及其具体分数带入独立阅读稿。不能把它改称自造算例。
