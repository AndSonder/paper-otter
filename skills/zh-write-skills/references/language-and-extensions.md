# 中文修订与延伸阅读

修订中文或安排延伸阅读时读取。

用连续中文讲清谁做了什么、为什么。指代可能混淆就写对象名；一句同时塞了对象、条件、操作和结果，就按因果关系拆开。不要照搬英文修饰顺序，也不机械拆成碎句。必要术语可以保留英文，但别让角色名反复中英切换。

读到拗口的句子，先用普通话说出它的意思，再写回正文，确认条件与因果没丢。抽象词能否对应到具体操作？新段落是否接住上段的疑问？标题帮助找回主线，列表只用于真正并列的信息。例句见 [references/chinese-and-figures.md](chinese-and-figures.md)。

少写宣布重要性、泛泛总结和边界清单。结尾回应开头：读者现在能算什么、选什么或判断什么。若正文已回答完整，可以直接结束。

用户希望拓展阅读时，从本文已经显现的限制、另一种设计选择或尚未展开的机制引出少量相关技术。每个入口用短段说明：它接着回答哪个问题、主要改变什么、与本文的联系，以及下一篇值得深入什么，并给出实际读过且支持介绍的原始来源。相关技术的结论要核验，不凭名称或年代编造演进关系。不在当前正文展开整篇后续文章，也不以名字和链接列表代替介绍。扩展不能补救本文核心解释的缺失；后续文章尚未生成时标为阅读方向，不伪造本站文章链接。
